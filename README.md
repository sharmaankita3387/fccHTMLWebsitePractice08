## About This Project  
This is Project 8 in my coding practice series. In this project, I focused on structuring a complete blog-style webpage using semantic HTML elements.

The goal was to properly organize content into meaningful sections like header, navigation, main content, and footer, while also practicing how different elements work together to create a clean and readable layout.

---

## Guiding Principle  
> "To become a reliable VibeCoder, you must first understand what’s happening behind the scenes as a Software Engineer."

---

## Key Concepts Practiced  
- Structuring a webpage using semantic elements like `<header>`, `<main>`, `<section>`, and `<footer>`  
- Creating navigation using anchor links for internal page sections  
- Organizing content using the `<article>` element  
- Using the `<figure>` and `<figcaption>` elements for images  
- Implementing the `<address>` element for contact information  
- Using `tel:` and `mailto:` links for direct interaction  

---

## Why This Project Matters  
A well-structured HTML layout is the foundation of every good website. This project reinforces the importance of semantic structure, which improves accessibility, readability, and scalability for future styling and functionality.
